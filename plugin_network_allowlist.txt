# רשימת ה-URLs המאושרים לגישת רשת של תוספי אוצריא.
#
# ענף זה (plugin-network-allowlist) ייעודי לקובץ הזה בלבד. עריכה כאן
# נכנסת לתוקף מיד אצל כל המשתמשים, בכל גרסה מותקנת — אין צורך ב-release.
#
# פורמט: שורה = קידומת URL אחת. שורות ריקות ושורות שמתחילות ב-# מדולגות.
# כל ערך הוא קידומת (prefix): מאושרים ה-URL עצמו וכל תתי-הנתיבים תחתיו
# (מופרדים ב-/, ? או #), ולא שאר הדומיין.
#
# כללים:
# - חובה scheme מלא (https:// או http://).
# - דומיין שלם מתיר את כולו: https://api.example.com
# - אין להשאיר / סופי.
#
# זכרו: תוסף חייב להצהיר על הכתובת גם ב-network.allowlist במניפסט שלו —
# הרשימה כאן היא תנאי נוסף, לא תחליף.
