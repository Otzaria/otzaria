# מסדי ספרים אישיים

המדריך מיועד למשתמשים ולמי שבונה מסד ספרים משלו. מסד ספרים אישי הוא קובץ SQLite
במבנה של ספריית אוצריא (כמו `seforim.db`), שמצורף לספרייה ומוצג לצד הספרים הרשמיים
והאישיים. אפשר לצרף מסד אחד או כמה.

## צירוף מסד

הגדרות ← לשונית "ספרייה" ← הכרטיס **"מסדי ספרים אישיים"**:

- **"ייבא קובץ מסד"** — בחירת קובץ `.db` בודד.
- **"הוסף תיקיית מסדים"** — כל קובץ `*.db` בתיקייה מצורף. התיקייה נסרקת אחרי עליית
  התוכנה ובסריקה ידנית חוזרת.

### מצבי צירוף

| מצב | ברירת מחדל ב- | התנהגות |
|---|---|---|
| קישור במקום | מחשב | הקובץ נקרא במקומו ולעולם אינו משתנה. מסד שיש לו קובץ `-wal` או journal "חם" נדחה — יש לסגור אותו כראוי בכלי שיצר אותו. |
| העתקה | נייד | הקובץ מועתק לתיקיית נתוני התוכנה, לתיקייה "מסדים אישיים". ה-journal מנורמל על ההעתק. |

### פעולות לכל מסד

- **מיקום בעץ**: "בנפרד" — תחת השורש "ספרים אישיים/<שם התצוגה>"; או "ממוזג" — הספרים
  משתלבים בקטגוריות הספרייה לפי כותרת הקטגוריה. ספרי מסד מצורף תמיד ממוינים אחרי
  הספרים הרשמיים והאישיים.
- **הסתרה**, **סדר עדיפות** בין המסדים.
- **"שחרר קובץ"** — משחרר את נעילת הקובץ ב-Windows כדי שאפשר יהיה להחליף אותו.
- **הסרה** — קובץ מקושר לעולם אינו נמחק; העתק מנוהל נמחק אחרי אישור.

### מסד לא זמין או איטי

- מסד שאינו נגיש (כונן נשלף, כונן רשת): הספרים שלו מוסתרים והסטטוס "לא זמין", אבל
  ההגדרות, אינדקס החיפוש, הסימניות וההערות נשמרים. כשהמסד חוזר — הכול חוזר.
- לכל מסד תקציב זמן משלו בבניית עץ הספרייה. מסד שלא עונה מסומן "לא זמין" והעץ ממשיך
  להיבנות בלעדיו.

## זהות המסד (slug)

- ה-slug נלקח מ-`schema_meta.library_id` אם קיים, אחרת משם הקובץ אחרי ניקוי.
- תווים מותרים: אותיות (כולל עברית), ספרות, `.` `_` `-`; עד 64 תווים.
- שני קבצים עם אותו slug — השני נדחה.
- **שמרו על `library_id` יציב בין גרסאות** — עליו נשענים סימניות, אינדקס החיפוש והערות.
- החלפת הקובץ בגרסה חדשה (אותו slug) ← רק ספרי המסד הזה מאונדקסים מחדש.

מפתחות `schema_meta` שנקראים: `library_id`, `display_name`, `db_version`; וכן
`description`, `author` (אופציונליים, לידיעה בלבד).

## קטלוג הטבלאות

**אף טבלה אינה חובה.** טבלה חסרה ← רק היכולת התלויה בה ריקה. מסד מינימלי שימושי:
`book` + `line`.

| טבלה / זוג | תפקיד | הערות |
|---|---|---|
| `category` | עץ הקטגוריות | בלעדיה הספרים יושבים ישירות תחת שורש המסד |
| `book` | הספרים | עמודות אופציונליות: `heDesc`, `orderIndex`, `filePath` |
| `line` | טקסט הספר | שורה אחת לכל רשומה, `lineIndex` מתחיל מ-0 |
| `tocText` + `tocEntry` | תוכן עניינים | |
| `line_toc` | פירורי לחם (מיקום בתוכן העניינים) | |
| `author` + `book_author` | פרטי ספר: מחבר | |
| `topic` + `book_topic` | פרטי ספר: נושאים | |
| `pub_place` + `book_pub_place` | פרטי ספר: מקום הוצאה | |
| `pub_date` + `book_pub_date` | פרטי ספר: שנת הוצאה | |
| `generation` + `book_generation` | דור/תקופה | קיבוץ ומיון מפרשים |
| `connection_type` + `link` | קישורים ומפרשים בתוך אותו מסד | |
| `link_anchor` | עוגני מילים לקישורים | |
| `link_range` + `link_coverage` | טווחי קישור | **חייבות לבוא יחד** |
| `link_suppressed_side` | הסתרת צד של קישור | |
| `default_commentator` / `default_targum` | ברירות מחדל לצורת הדף | |
| `alt_toc_structure` + `alt_toc_entry` (+ `line_alt_toc`) | לשונית "כותרות" | |
| `line_dh` | דיבור המתחיל | עמודה `dhDisplay` |
| `line_ref` | אינדקס הפניות | איתור מקור עד השורה המדויקת |
| `book_acronym` | ראשי תיבות | לחיפוש ספרים ולאיתור |
| `book_version` + `version_line` | מהדורות | **חייבות לבוא יחד** |
| `schema_meta` | מטא-דאטה של המסד | ראו למעלה |
| `external_link` | קישורים בין מסדים | ראו בהמשך |

כל טבלה אחרת (כולל טבלאות שנראות כמו טבלאות תוספים) **מתעלמים ממנה ולעולם אינה
נקראת**. שם טבלה מוכר שהוא VIEW או טבלה וירטואלית — מתעלמים ממנו.

### `book.filePath`

עמודה אופציונלית (למשל לקובץ PDF). הנתיב חייב להיות **יחסי לתיקיית המסד**. נדחים:
נתיב מוחלט, אות כונן, UNC, `..`, רכיב שכולו נקודות/רווחים, `:`, תו NUL.

### אינדקסים מומלצים למסד גדול

```sql
CREATE INDEX idx_line_book_index ON line(bookId, lineIndex);  -- רצוי אינדקס מכסה
CREATE INDEX idx_link_source ON link(sourceBookId, sourceLineId);
CREATE INDEX idx_link_target ON link(targetBookId, targetLineId);
CREATE INDEX idx_toc_entry_book ON tocEntry(bookId);
CREATE INDEX idx_external_link_source ON external_link(sourceBookId, sourceLineIndex);
```

## קישורים בין מסדים — `external_link`

| עמודה | טיפוס | משמעות |
|---|---|---|
| `sourceBookId` | INTEGER | `book.id` במסד הזה |
| `sourceLineIndex` | INTEGER | שורת המקור (מ-0) |
| `targetSource` | TEXT | `'official'`, או `library_id` של מסד מצורף אחר, או NULL = כל מקור (קודם הרשמי, אחר כך המסדים המצורפים לפי עדיפות) |
| `targetTitle` | TEXT | כותרת ספר היעד |
| `targetRef` | TEXT | heRef של היעד — מועדף; מתורגם דרך `line_ref` של מסד היעד |
| `targetLineIndex` | INTEGER | גיבוי (מ-0) כשאין `targetRef` |
| `connectionType` | TEXT | NULL ← `REFERENCE` |

ל-`connectionType` **אותה משמעות כמו בטבלת `link` הרשמית**: איך היעד מוצג לקורא בספר
המקור. לכן, כדי שהפירוש שלכם יופיע בחלונית המפרשים של ספר רשמי, כתבו
`connectionType='SOURCE'` — מבחינת הפירוש שלכם, הספר הרשמי הוא המקור:

```sql
CREATE TABLE external_link (
  sourceBookId INTEGER NOT NULL,
  sourceLineIndex INTEGER NOT NULL,
  targetSource TEXT,
  targetTitle TEXT NOT NULL,
  targetRef TEXT,
  targetLineIndex INTEGER,
  connectionType TEXT
);

-- שורה 0 של "פירוש על ספר א" (book.id = 1 במסד שלכם) מפרשת את "ספר א" הרשמי.
-- כך הפירוש יופיע בחלונית המפרשים של "ספר א".
INSERT INTO external_link
  (sourceBookId, sourceLineIndex, targetSource, targetTitle, targetRef, targetLineIndex, connectionType)
VALUES
  (1, 0, 'official', 'ספר א', 'ספר א א, א', NULL, 'SOURCE');
```

- הקישורים ההפוכים (מהספר הרשמי אל הפירוש) מוגשים מאינדקס צד שהתוכנה בונה ב-`cache.db`;
  הוא נבנה מחדש כשהקובץ שלכם או גרסת הספרייה הרשמית משתנים.
- מגבלות: עד 500,000 שורות למסד (מעבר לזה הטבלה מדולגת); כותרת והפניה נחתכות ב-512 תווים.

## גרסאות: ספר אישי כגרסה של ספר אחר

קובץ `גרסאות.csv` / `versions.csv` — כקובץ צד בתיקיית ספרים אישיים, או בייבוא ידני
בהגדרות. עמודות: `ראשי`, `גרסה`, [`שם`], [`הערות`], [`עדיפות`], [`מקור_ראשי`],
[`קטגוריית_ראשי`].

`מקור_ראשי`:

| ערך | הספר הראשי הוא |
|---|---|
| ריק / `אישי` / `user` | ספר אישי (ההתנהגות הקודמת — קבצים ישנים לא משתנים) |
| `רשמי` / `official` | ספר מהספרייה הרשמית |
| `מסד:<id>` / `db:<id>` | ספר במסד מצורף |

- ספר ראשי שאינו אישי מצוין תמיד **לפי כותרת** (לא לפי מזהה מספרי), כדי לשרוד עדכוני
  ספרייה. `קטגוריית_ראשי` מבחינה בין ספרים בעלי כותרת זהה.
- ראשי שלא נמצא ← הספר האישי נשאר ספר רגיל ועצמאי.
- דיאלוג הגרסאות של הספר הראשי ובורר הגרסאות בקורא מציגים את הגרסאות האישיות; בחירה
  פותחת את הספר האישי בכרטיסייה סמוכה.

```csv
ראשי,גרסה,שם,הערות,עדיפות,מקור_ראשי,קטגוריית_ראשי
ספר א,ספר א - מהדורה שלי,מהדורה מתוקנת,,1,רשמי,
ספר ב,ספר ב - העתק,,,2,db:my-library,קטגוריה א
```

## מה נתמך בספרי מסד מצורף

עץ הספרייה, קריאה, תוכן עניינים, קישורים ומפרשים (מקובצים לפי דור), צורת הדף,
"כותרות", דיבור המתחיל, מהדורות, PDF (נתיב יחסי), אינדקס חיפוש מלא (ספרים מצורפים
נוספים בסוף סדר הקטלוג, כך שצירוף מסד אינו מאנדקס מחדש ספרים אחרים), איתור מקורות
(כותרת, ראשי תיבות, תוכן עניינים, שורה מדויקת דרך `line_ref`; מוצג כשהאפשרות "כלול
ספרים אישיים" פעילה), חיפוש ספרים בספרייה (מדורגים אחרי רשמיים ואישיים), הדפסה,
הערות אישיות, סימניות והיסטוריה, ו-API התוספים.

**רק לספרייה הרשמית:** "דווח על טעות" ו"שמור וזכור".

## אבטחה

- המסד נפתח לקריאה בלבד: `query_only`, `trusted_schema=OFF`, מצב defensive, ללא
  הרחבות, mmap כבוי. לעולם לא נכתב אליו.
- **שום דבר מהמסד אינו מותקן או מורץ** — לא תוספים, לא סקריפטים, לא גופנים.
- קישורים שמוטמעים בטקסט הספר יכולים רק לנווט.
- נתיבי קבצים מוגבלים לתיקיית המסד.

## בדיקת מסד לפני הפצה

```bash
dart run tool/validate_personal_db.dart <path-to-db>
```

מדפיס דוח יכולות: טבלאות שנמצאו / חסרות / שמתעלמים מהן, זוגות לא שלמים, VIEW שמתחזה
לטבלה, ה-slug שנגזר, מצב WAL, מספר שורות `external_link` מול המגבלה, והפרות
`filePath`. יוצא בקוד שאינו 0 כשיש בעיה חוסמת.

## פתרון תקלות

| תסמין | סיבה ופתרון |
|---|---|
| המסד נדחה בצירוף כקישור | יש לו `-wal` או journal חם. סגרו אותו כראוי בכלי שיצר אותו (או הריצו `PRAGMA wal_checkpoint(TRUNCATE)` ו-`PRAGMA journal_mode=DELETE`). |
| מסד שני נדחה למרות שהקובץ תקין | שני קבצים עם אותו `library_id` / שם קובץ. שנו את אחד המזהים. |
| סימניות והערות "נעלמו" אחרי עדכון המסד | `library_id` השתנה בין הגרסאות. החזירו את המזהה הקודם. |
| לא ניתן להחליף את הקובץ ב-Windows | "שחרר קובץ" בכרטיס המסד, ואז החליפו. |
| הספרים הופיעו ישירות תחת שורש המסד | אין טבלת `category`. |
| אין מפרשים / טווחים / מהדורות | בדקו זוגות חובה (`link_range`+`link_coverage`, `book_version`+`version_line`) עם הכלי. |
| הפירוש לא מופיע בחלונית המפרשים של הספר הרשמי | `connectionType` צריך להיות `'SOURCE'`; ודאו ש-`targetTitle`/`targetRef` תואמים ושהטבלה בגבול 500,000 השורות. |
| PDF לא נפתח | `filePath` חייב להיות יחסי לתיקיית המסד, בלי `..`. |
| סטטוס "לא זמין" | הכונן מנותק או שהמסד לא ענה בזמן. חברו מחדש והפעילו סריקה ידנית. |
