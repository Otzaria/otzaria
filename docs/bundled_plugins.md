# תוספים מצורפים למתקין

מנגנון שמאפשר למתקיני Windows (רגיל, FULL, indexed-FULL, ARM64) להגיע עם
תוספים מהחנות הרשמית מותקנים מראש.

## איך מוסיפים תוסף

מוסיפים את מזהה התוסף ל-`lib/plugins/services/bundled_plugin_ids.dart`,
מזהה אחד בשורה:

```dart
const bundledPluginIds = <String>{
  'my.plugin.id',
};
```

זה הכל. הרשימה הזו היא גם רשימת ההיתר שהאפליקציה אוכפת וגם המקור שממנו
ה-workflow יודע מה להוריד — מקור אחד, בלי סנכרון ידני.

## איך זה עובד

1. **בזמן ה-build בגיטהאב** — `installer/download_bundled_plugins.ps1` קורא את
   הרשימה, מוריד כל תוסף מהחנות (`otzaria.org/api/plugins/<id>/download` עם
   `appVersion` כדי לקבל גרסה תואמת), מאמת שהקובץ הוא ZIP, ומניח אותו
   ב-`installer/bundled_plugins/<id>.otzplugin`. רשימה ריקה — השלב לא עושה דבר.
2. **המתקין** מעתיק את התיקייה ל-`{app}\bundled_plugins` (עם
   `skipifsourcedoesntexist`, כך שבנייה מקומית בלי התוספים עובדת כרגיל).
   שדרוג מוחק קודם את התיקייה הישנה (`[InstallDelete]`).
3. **בעליית אוצריא** — `BundledPluginSeedService` (דרך אירוע
   `SeedBundledPlugins` ב-`PluginSystemBloc`) סורק את התיקייה ומתקין דרך
   מסלול ההתקנה הרגיל (`prepareInstall`/`finalizeInstall`, כולל ולידציית
   מניפסט מלאה) כל תוסף שעונה על כל התנאים:
   - המזהה נמצא ב-`bundledPluginIds` המקומפל לתוך האפליקציה;
   - המזהה שהמניפסט מצהיר זהה לשם הקובץ;
   - התוסף לא נרשם בעבר מהמנגנון הזה (`key-seeded-bundled-plugins`)
     ואינו מותקן כבר.

   הרשאות המניפסט מוענקות במלואן — התוספים נבחרים ידנית ע"י המפתחים
   ומגיעים מהחנות הרשמית ב-https בלבד.

## אבטחה

הנחת קובץ `.otzplugin` בתיקייה **אינה** מספיקה להתקנה: המזהה חייב להופיע
ברשימת ההיתר שמקומפלת לתוך ה-exe, והמניפסט חייב להצהיר בדיוק על אותו מזהה.
גורם חיצוני שיכול להחליף את הרשימה המקומפלת יכול ממילא להחליף את ה-exe
כולו, כך שהמנגנון אינו מוסיף משטח תקיפה מעבר לקיים.

## למה הרישום קורה בעלייה ולא במתקין

התקנת תוסף היא רישום פר-משתמש: קבצים תחת נתוני המשתמש + שורות
ב-`plugins_host.db` + הענקות הרשאות. המתקין רץ פעם אחת (ולעיתים כמנהל,
עבור כל המשתמשים) ואינו יכול לכתוב ל-DB שהסכמה שלו מנוהלת ע"י האפליקציה.
לכן המתקין רק מניח את הארכיונים, והאפליקציה רושמת אותם בפתיחה הראשונה של
כל משתמש — לפני שמסך הכלים נטען, כך שמבחינת המשתמש הם "הגיעו מותקנים".

תוסף שהמשתמש הסיר לא יחזור: הרישום מסומן ב-`key-seeded-bundled-plugins`
ואינו מנוסה שוב, גם אחרי שדרוג.
