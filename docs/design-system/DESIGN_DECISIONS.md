   - **Android:** Roboto לטינית + Noto Sans Hebrew.
   - **Linux ו־macOS:** תלוי בגופני המערכת.
   - **תוספים:** מקבלים `uiFontFamily: 'Rubik'`.
2. **המצב היום:**
   - 'Roboto' קשיח ב־8 מקומות (`app_theme_data.dart:95,159,216,241`, `app_popup_menu.dart:920,1051`, `menu_rows.dart:60,186,266`).
   - הבדיקות טוענות את Rubik בשם 'Roboto'.
   - לסבבים הקודמים צולמו תמונות עם Segoe UI.
3. **אפשרויות:**
   - **A. גופני מערכת במפורש:**
     - `fontFamily: null` (ברירת המחדל של הפלטפורמה).
     - `fontFamilyFallback: ['Segoe UI', 'SF Pro Text', '.AppleSystemUIFont', 'Noto Sans Hebrew', 'Arial']` לפי פלטפורמה, כלומר הסטת ה־fallback למקום אחד.
   - **B. Rubik כלול כגופן הממשק:**
     - כבר נמצא במאגר ומכסה עברית ולטינית.
     - כבר משמש את התוספים.
   - **C. לכלול Roboto + Noto Sans Hebrew:** גופן ממשק "מותג" עקבי בכל הפלטפורמות.
4. **יתרונות וחסרונות:**
   - **A:** אין שינוי חזותי ב־Windows (Segoe UI נשאר), ההתנהגות נעשית צפויה, ואין תוספת לגודל ההתקנה. מנגד, המראה עדיין שונה בין פלטפורמות.

     - שינוי חזותי בולט.

   - **C:** מראה M3 מוכר. מנגד, תוספת של כ־1MB להתקנה, ושני גופנים בכל תווית מעורבת.
