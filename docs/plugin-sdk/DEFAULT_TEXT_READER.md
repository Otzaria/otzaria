# תוסף כקורא טקסט בתוך כרטיסיית ספר

הרחבה זו מאפשרת לתוסף להחליף את אזור הטקסט בכרטיסיית ספר רגילה. זהות הספר, הסרגל, חלוניות תוכן העניינים/החיפוש/המפרשים, היסטוריה ושמירת כרטיסיות נשארים בידי אוצריא. היא מיועדת, למשל, לתצוגת טורים. התוסף מספק את התצוגה דרך דף ה־WebView שלו; אין שינוי במנוע הספרים או בתוכן שלהם.

## בחירה והרשאות

`reader.getDefaultTextReader({})` מחזיר `{pluginId, enabled, available}`. `enabled` מציין שהתוסף הקורא הוא בחירת המשתמש; `available` מציין שהקורא הנבחר זמין כעת. יש לבדוק תמיכה ולטפל בשגיאת שיטה שאינה קיימת כשמריצים תוסף על גרסה קודמת של אוצריא.

`reader.setDefaultTextReader({enabled: true|false})` שומר את הבחירה. נדרשים תוסף מופעל בעל דף, הרשאות מוענקות `reader.open`, `library.books.read`, `library.content.read`, ומחוות משתמש במופע קדמי. קריאה ברקע נדחית. תוסף אחר אינו יכול לבטל בחירה שאינה שלו.

הבחירה נשמרת ב־`key-plugin-default-text-reader`. כשהתוסף כבוי, מוסר, חסר הרשאות או כשאוצריא במצב בטוח, מוצג הקורא המובנה. ההעדפה נשמרת בלי לכפות הפעלה מחדש של תוסף. כיבוי הבחירה או בחירה חדשה מסירים עקיפות זמניות בכרטיסיות.

ההחלפה חלה על ספרים מסוג `text`. PDF, EPUB, DOCX וצורת הדף ממשיכים להשתמש בקוראים המובנים שלהם.

## מופע לכל כרטיסיית ספר

לכל `TextBookTab` מוקצה מזהה מופע נפרד, גם כששתי כרטיסיות מציגות אותו ספר. רק מופעים של כרטיסיות גלויות נחשבים קדמיים. במופע משובץ, `plugin.boot` כולל שדה `reader`:

```json
{
  "reader": {
    "embedded": true,
    "nativeToolbar": true,
    "bookUid": "...",
    "id": 42,
    "bookId": "בראשית",
    "title": "בראשית",
    "type": "text",
    "source": "library",
    "currentIndex": 12,
    "searchQuery": "...",
    "display": {"fontSize": 20, "profile": {}}
  }
}
```

שדות זהות הספר משתמשים בחוזה SDK הקיים. `currentIndex` הוא אינדקס שורת מקור החל מ־0, ולא מספר טור/עמוד בתוסף. יש לקרוא את הספר דרך `library.getBookContent` ואת תוכן העניינים דרך `library.getBookToc`. אין לשחזר ספר אחר מהאחסון הפרטי של התוסף בתוך המופע המשובץ.

## ניווט ומיקום

- `reader.textReaderNavigate` נשלח למופע הכרטיסייה כאשר תוכן העניינים, החיפוש או פתיחה חוזרת מבקשים מיקום חדש. המטען הוא אותו אובייקט `reader` שב־boot. אם הטקסט עדיין נטען, יש לשמור את יעד הניווט עד שאפשר להציגו.
- `reader.reportTextReaderLocation({index, ref?})` מסנכרן מיקום עם הכרטיסייה הקשורה למופע, גם אם המשתמש עבר לספר אחר. `index` חייב להיות מספר שלם שאינו שלילי; `ref` הוא כותרת מיקום עד 500 תווים. רק הקורא הפעיל של הכרטיסייה רשאי לדווח. מצב הקורא המובנה מסונכרן לפני שמירת הכרטיסיות.
- לפתיחת ספר אחר משתמשים ב־`reader.openBook`; אין להחליף את זהות הספר בתוך המופע.

## סרגל ותצוגה

`reader.textReaderCommand` נשלח למופע הספר ומכיל את זהות הספר ואת `action`:

| action | תפקיד |
|--------|-------|
| `settings` | פתיחת הגדרות התצוגה של התוסף |
| `advance` | דפדוף בתצוגת התוסף; `direction` הוא `-1` או `1` |
| `display` | החלת `display` מעודכן בעקבות גודל אות, ניקוד או פיסוק |

התוסף צריך להתעלם מאירועים לזהות ספר אחרת. עם `nativeToolbar: true` אפשר להסתיר את הכותרת המקומית של התוסף; בכרטיסייה עצמאית יש להשאיר את פקדי התוסף זמינים.

`reader.setTextReaderFontSize({fontSize})` משנה את גודל האות בכרטיסייה המשובצת הפעילה. מותר מספר סופי בין 14 ל־60; קריאה ממופע רקע, ממופע ללא כרטיסייה או מקורא שהוחלף נדחית.

`library.getBookContent({...identity, textReaderDisplay: true})` מחיל את פרופיל התצוגה של הכרטיסייה על כל שורת מקור בנפרד. שורות פנימיות שנוצרות מה־HTML מוחזרות כ־`<br>`, ומספר שורות המקור נשמר. `offset`/`limit` נשארים ביחידות UTF-16. האפשרות זמינה רק לספר הקשור למופע; בלי הדגל הקריאה הרגילה אינה משתנה. שינוי פרופיל מחייב טעינה מחדש תוך שמירת יעד שורת המקור, גם אם השינוי הגיע במהלך הטעינה הראשונית.

## חזרה לקורא המובנה

`reader.openBook({...identity, index, reader: 'native'})` פותח את הספר בקורא המובנה באותו מיקום, בלי לבטל את ההעדפה עבור שאר הספרים. העקיפה תקפה לכרטיסייה החיה בלבד. פעולת **קורא רגיל** בסרגל המארח זמינה גם כשה־WebView נכשל; **הגדרות קורא התוסף** שולחת את פקודת `settings`.

ההחלפה היא של `CombinedView` בתוך `SplitedViewScreen` בלבד. בקר הניווט החלופי מנותק בחזרה לקורא הרגיל ובהסרת המופע. טעינה ראשונה של הקורא המובנה משתמשת במיקום הכרטיסייה המעודכן; טעינה חוזרת שומרת את המיקום שכבר נטען.
