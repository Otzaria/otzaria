## 2024-06-27 - Flattening nested widgets in ListView.builder for Flutter optimization
**Learning:** In Flutter, eagerly pre-building a `List<Widget>` and then passing it to a `ListView(children: ...)` or wrapping it somehow completely defeats the purpose and memory benefits of lazy loading, since all widgets are instantiated at once. We need to flatten the underlying data model recursively into a flat list of data items (like `LibraryItem`), and then use `ListView.builder` over that flattened list so widgets are only built when they scroll into view.
**Action:** When finding `ListView(children: ...)` or similar where the children list is pre-computed (e.g. `_buildCategoryTree`), refactor the tree traversal to return a flattened list of data models, and use `ListView.builder` with `itemCount` and `itemBuilder` to render the items on-demand.
