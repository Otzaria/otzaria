# otzaria_context_menu

חבילת Flutter פנימית לתפריטי הקשר השומרים על בחירת הטקסט, ולתתי־תפריט משותפים לתפריטי הקשר ולתפריטים הנפתחים מכפתור. החבילה אינה מיועדת לפרסום ב־pub.dev.

`ContextMenuRegion` מנהל את המחוות, מיקום התפריט, הרינדור וסגירת תתי־התפריט לפי עומק. הוא מקבל `MenuPresentation` למידות ולאייקונים, ו־`registerEscape` המחזיר פונקציית ביטול רישום. המארח קובע את סדר שכבות Escape.

`onMenuOpening` מופעל לפני הכנסת ה־overlay. המארח יכול ללכוד בו עוגן גלילה לתצוגה מקדימה. `onMenuClosed` מופעל פעם אחת בכל סגירת תפריט פתוח (כולל החלפה או פירוק ה־widget), כדי לשחרר עוגנים והפניות ל־RenderObject ולגלילה. `previewWrapper` מחבר את פריטי התפריט לחלונית המקדימה ומקבל callback לסגירת התפריט לאחר קיבוע החלונית.

`AppSubmenuButton` מבוסס על תשתית התפריטים של Flutter. בתפריט הקשר יש לשמור `preserveFocus: true` ולמנוע פוקוס גם בפאנל האב, כדי שפתיחת ילד לא תנקה את בחירת המקור. תפריט הנפתח מכפתור משתמש ב־`preserveFocus: false` ומאפשר הפעלה במקלדת.

באפליקציה נשארים העיצוב, אייקוני Fluent/Otzaria, תצוגות מקדימות של ספרים, שדות טקסט וחיפוש, וכל בניית הפעולות העסקיות. קובצי `app_context_menu.dart` ו־`app_popup_menu.dart` שומרים על ממשקי האפליקציה הקיימים באמצעות מתאמים ו־exports.

בדיקות עצמאיות, מתוך תיקיית החבילה:

```sh
flutter pub get
flutter analyze --fatal-infos
flutter test
dart format --output=none --set-exit-if-changed lib test
```

בדיקות שילוב עם היישום נשארות תחת `test/widgets/` ותיקיות התכונות המשתמשות בתפריטים.
